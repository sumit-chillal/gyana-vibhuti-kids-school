# Gyana Vibhuti Kids School Website

A premium modern school website developed for **Gyana Vibhuti Kids School** with a clean parent-first user experience, responsive design, and elegant UI inspired by leading international school websites.

Built using **React**, **Tailwind CSS**, and **Framer Motion**, the platform focuses on modern design, smooth interactions, accessibility, and a professional digital presence for early education.

## Features

* Premium responsive UI/UX
* Parent-first navigation
* Admissions-focused design
* Modern animations and transitions
* Gallery and campus showcase
* Mobile-friendly experience
* Optimized performance
* Clean and scalable frontend architecture

## Tech Stack

* React
* Tailwind CSS
* Framer Motion
* JavaScript
